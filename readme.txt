# 🚗 CRS - Car Rental System

A web-based Car Rental System developed as a final project by students from the Faculty of Informatics, Burapha University.

## 📌 Project Overview

The CRS system provides features for managing car rentals, customers, and rental transactions. It supports admin functionalities for car management and user bookings through a simple web interface.

## 🛠️ Technologies Used

- **Backend**: PHP 7.3  
- **Database**: MySQL (via XAMPP)  
- **Frontend**: HTML, CSS, JavaScript  
- **Web Server**: Apache (XAMPP)
